# Ideas

This folder is the raw idea inbox.

Use `[HUMAN]`, `[AGENT]`, and `[MIXED]` filename and heading prefixes to preserve idea origin:

```text
[HUMAN]-try-transfer-before-full-gate.md
[AGENT]-mine-rare-tier-failures.md
[MIXED]-gate-headroom-rule.md
```

Idea file shape:

```markdown
# [HUMAN] Short mechanism idea

Source: operator
Status: raw | testing | promoted | rejected

## Idea

<the mechanism, intervention, memory, policy, or attribution idea>

## Evidence

<links to research_log.md, traces, receipts, or findings>

## Next

<next mechanism test or reason parked>
```

Promote evidence-backed ideas into `findings/ideas/` and link back here. Do not erase raw human phrasing when promoting.
